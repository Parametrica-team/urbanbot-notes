# План полноценной RAG-базы

Цель: проверяемые ответы по нормативам с редакцией, пунктом и ссылкой; локальный бесплатный запуск и возможность серверного размещения.

## Критерии приёмки

- [ ] Реестр источников: документ, редакция, изменения, область охвата, URL, SHA-256, статус проверки.
- [ ] Корпус: исходные тексты сохранены; пункт, условия, таблицы и исключения не разорваны при разбиении.
- [ ] Проверенный первый раздел по пожарным проездам; непроверенные СП и СанПиН явно исключены из нормативных ответов.
- [ ] Индекс: SQLite FTS + семантический поиск, фильтры редакций и статусов; атомарная пересборка и удаление устаревших фрагментов.
- [ ] Генерация локальной моделью: ссылки на найденные пункты; отказ при недостатке данных; источники не исполняются как инструкции.
- [ ] Интерфейс: вопрос, ответ, список оснований и границы покрытия; работа с ошибками модели.
- [ ] Обновление из Obsidian: одна команда, проверка изменений и повторная оценка.
- [ ] Контрольные вопросы: границы высоты, область применения Ф1–Ф4/Ф5, архив, неизвестные вопросы, инъекции, недоступная модель.
- [ ] Реальный end-to-end прогон с моделями, без подмены ответа заглушкой.
- [ ] Документированы запуск, остановка, резервная копия, стоимость и границы удалённого доступа.

## Очередь наполнения

1. СП 4: раздел 8 и область применения; официальные изменения.
2. СП 42.2026, СП 476 и СП 396: дворы, кварталы, УДС.
3. СП 113, СП 59 и СП 551: паркинги, доступность, пожарная безопасность.
4. СанПиН 2.1.3684 и 1.2.3685: полный актуальный текст, таблицы и условия.
5. Региональные НГП/МНГП, ПЗЗ: отдельный регион и проектная применимость.

Критерий «полностью проверена вся нормативная база» нельзя выполнить добавлением одних карточек: каждый документ проходит сверку отдельно. Незавершённые позиции остаются открытыми.
