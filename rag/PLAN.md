# План полноценной RAG-базы

Цель: проверяемые ответы по нормативам с редакцией, пунктом и ссылкой; локальный бесплатный запуск. По решению пользователя от 30.10.2026 чат остаётся локальным; командный сервер не входит в этот этап.

## Критерии приёмки

- [x] Реестр источников: документ, редакция, изменения, область охвата, URL, SHA-256, статус проверки. У каждого из девяти документов есть ограниченное проверенное подмножество; остальной текст остаётся в очереди.
- [x] Корпус первого источника: исходные тексты сохранены; пункт, условия и исключения не разорваны при разбиении. Таблицы вне одобренных выдержек остаются в очереди сверки.
- [x] Проверенное подмножество по пожарным проездам; пять спорных пунктов СП 4 и непроверенные части СП/СанПиН исключены из актуальных нормативных ответов.
- [x] Индекс: SQLite FTS + семантический поиск, фильтры редакций, статусов и дат; атомарная пересборка, кеш и удаление устаревших фрагментов.
- [x] Генерация локальной моделью: ссылки на найденные пункты; отказ при недостатке данных; источники не исполняются как инструкции. Реализован извлекающий режим без свободных числовых пересказов; качество проверяется отдельно.
- [x] Интерфейс: вопрос, ответ, список оснований и границы покрытия; работа с ошибками модели. Локальный интерфейс открыт и просмотрен.
- [x] Обновление из Obsidian: одна команда, отдельный слой рабочих заметок, проверка изменений и оценка кандидата до включения.
- [x] Контрольные вопросы: границы высоты, область применения Ф1–Ф4/Ф5, архив, неизвестные вопросы, инъекции, недоступная модель. 31 unit-тест и отдельные реальные проверки отказов.
- [x] Реальный end-to-end прогон с моделями, без подмены ответа заглушкой: 14/14 положительных случаев, 3/3 основных отрицательных, отказ для непроиндексированного документа и отдельный отказ при неполном покрытии СанПиН.
- [x] Документированы запуск, остановка, резервная копия, стоимость и границы удалённого доступа. Командный сервер не развёрнут.

## Ход проверки 30.10.2026

- Код прошёл отдельное ревью; исправлены проблемы обновления, редакций, дат и фильтрации документов.
- 31 unit-тест проходит, в том числе проверка полного совпадения каждого структурированного пункта с текстом в индексе, границ высоты, исторического режима, строгой схемы выбора, отказа от обхода источников и смены весов эмбеддингов. Принята Qwen3 4B Instruct 2507 (Apache 2.0), локально на CPU.
- Финальный реальный прогон прошёл все 14 положительных случаев по девяти документам и все сценарии отказов. Предварительные прогоны с неверным выбором пункта, оборванным JSON или нерелевантным ответом не были приняты. Новый индекс включён только после успешной оценки.
- Отчёт: [verification-2026-10-30.json](verification-2026-10-30.json), с digest моделей, версией runtime, SHA-256 кода/реестра и фактически выбранными ID пунктов. Проверено сохранение хешируемых байтов при Git checkout.
- 19 из 24 пунктов раздела 8 совпали при сверке; 5 расхождений остаются открытыми. Подробности: `sources/sp4-comparison.json`.
- Добавлены 54 текущих пункта по девяти документам и 24 архивных пункта СП 4. Для открытых копий указан `mirror`; полные официальные тексты не объявлены сверенными. СанПиН 1.2.3685 включён только в объёме пункта 165 о методе расчёта.

## Очередь наполнения

1. СП 4: раздел 8 и область применения; официальные изменения.
2. СП 42.2026, СП 476 и СП 396: дворы, кварталы, УДС.
3. СП 113, СП 59 и СП 551: паркинги, доступность, пожарная безопасность.
4. СанПиН 2.1.3684 и 1.2.3685: полный актуальный текст, таблицы и условия.
5. Региональные НГП/МНГП, ПЗЗ: отдельный регион и проектная применимость.

Критерий «полностью проверена вся нормативная база» нельзя выполнить добавлением одних карточек: каждый документ проходит сверку отдельно. Незавершённые позиции остаются открытыми.
